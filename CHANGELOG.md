# Changelog

## v0.1.0-alpha.1 — 2026-09-17

First public experimental preview of DraftLedger.

- Added governed registers for facts, assumptions, instructions, decisions, and open items.
- Added deterministic context compilation, declared provenance, contamination checks, and semantic-retrieval gating.
- Added state diff, decision revalidation, and append-only local state version control.
- Added strict and bounded JSON handling, atomic writes, repository locking, and release hardening checks.
- Added a machine-readable handoff board for multi-thread and multi-agent work, with single-owner claims, expiring leases, optimistic revisions, scope-collision checks, dependency tracking, progress events, takeover, cancellation, and completion.
- Added English and Chinese documentation, templates, examples, JSON Schemas, CI, deterministic release packaging, and a strict release audit.

This is an alpha. Public schemas, commands, and workflows may change before a stable release.
